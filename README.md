# 📱 µLearn UI Clone

A Flutter-based UI recreation of the µLearn mobile application, designed to replicate the authentication flow and profile dashboard with a clean, responsive interface.

This project demonstrates Flutter UI development, responsive layouts, reusable widgets, and modern Material Design principles.

---

## ✨ Features

- 🔐 Login Screen
- 📧 Login with Email & Password UI
- 🔑 Login with OTP UI
- 🔒 Forgot Password Screen
- 👤 User Registration Screen
- 📄 Profile Dashboard
- 📊 Karma Statistics Cards
- 🏆 Achievement Section
- 📈 Karma History
- 🤝 Connect With Me Section
- ⚙️ Profile Settings
- 📱 Responsive UI
- 🎨 Modern Material Design
